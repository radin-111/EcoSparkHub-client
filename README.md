# 🌱 EcoSparkHub
Link: [https://eco-spark-hub.vercel.app/](https://eco-spark-hub.vercel.app/)
### 🚀 Project Overview

EcoSparkHub is a simple crowdfunding platform focused on environmental ideas. It helps people share eco-friendly projects and get support from others who care about the planet 🌍.

Users can create campaigns, explore ideas, and contribute to projects they believe in 💚.

### ✨ What You Can Do

- Create and share eco projects 🌿

- Discover ideas that help the environment 🌎
- Manage your own campaigns easily ⚙️

EcoSparkHub is all about making small ideas grow into real impact 🌱➡️🌳.

### 🔑 Key Features

- 🔐 Secure user accounts
- 🧩 Create & manage campaigns
- 🛠️ Easy campaign management dashboard
- 📱 OTP verification for account security
- 📱 Clean, responsive design
- ⚡ Fast and smooth experience
- 🧯 Error handling & reliability
- 📊 Analytics & insights
- 💳 Payment integration
